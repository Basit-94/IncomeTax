# Awesome DESIGN.md Skill & Design System Guidelines

Based on the [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) repository and Google Stitch DESIGN.md specification.

## Core Philosophy
- **Plain-text Design Systems**: Maintain a machine-readable, human-delightful `DESIGN.md` in the project root defining visual tokens, typography hierarchies, card elevations, and color rules.
- **Editorial Voice & High Contrast**: Pair deep, authoritative backgrounds (such as slate/navy) with crisp ink typography and intentional accent highlights (gold/amber, emerald, sky blue).
- **Tactile Card Surfaces**: Components should feel physical—like printed documents, index cards, or sovereign passports—rather than flat abstract rectangles.
- **Micro-Interactions**: Subtle border glows, hover lifts, status chips, and monospaced cryptographic/statutory tags.

## Token Reference
- **Desk Canvas**: Warm graph-paper desk background (`--desk`, subtle grid).
- **Paper**: Index card surface (`--paper`, warm off-white or dark slate index cards).
- **Ink**: High-contrast typography (`--ink` deep charcoal/navy in light mode, crisp chalk white in dark mode).
- **Accents**:
  - Sovereign Gold / Amber: Trust, official CBDT stamps, warning alerts.
  - Money / Emerald: Tax savings, refund credits, validated accounts, primary CTAs.
  - Navy / Slate: Authority, institutional foundation, navigation bars.
