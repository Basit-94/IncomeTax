# Sequential Thinking MCP

Sequential Thinking enables step-by-step analytical reasoning, allowing the agent to break down multi-faceted problems, evaluate hypotheses, and verify invariant calculations.

## When to Use
- Computing complex Indian Income Tax scenarios across Old vs New Regimes (s. 115BAC).
- Calculating Section 87A rebate thresholds and marginal relief cliffs.
- Verifying reconciliation sync logic between the main citizen journey ledger (`lib/return/state.ts`) and the reconciliation context (`context/TaxReturnContext.tsx`).
- Planning refactors or bug investigations requiring deep root-cause tracing.
