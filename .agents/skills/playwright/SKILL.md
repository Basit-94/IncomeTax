# Playwright Browser Automation & UI Testing

Playwright MCP enables live browser control, DOM inspection, and interaction testing.

## When to Use
- Validating citizen journey flows on `http://localhost:3000` (onboarding, PAN input, OTP `949494`, facts review, deductions, regime selection, and filing).
- Verifying the `/reconcile` matrix and modal dialogs (Challan 280, Defective Notice, Bank IFSC).
- Checking responsive layouts across mobile and desktop viewports.
- Auditing UI layout integrity to guarantee zero visual degradation.
