# UI-Projects: Modern Component & Layout Patterns

Inspired by the [kpidiba/UI-PROJECTS](https://github.com/kpidiba/UI-PROJECTS) collection of modern web design components and layout patterns.

## Core Component Patterns
1. **Authentication Hubs**:
   - Clean, dual-column hero layout with narrative storytelling on the left and action/auth forms on the right.
   - Minimal input friction: reduce cognitive overload by asking only for strictly necessary identifiers (e.g. PAN).
   - High-contrast primary call-to-actions with clear progress indicators.

2. **Card Surfaces & Elevation**:
   - Multi-layered borders (`border border-line ring-1 ring-black/5 dark:ring-white/10`).
   - Subtle background gradients to create depth without visual noise.
   - Consistent padding scales: `p-4 sm:p-6 lg:p-8`.

3. **Status Badges & Chips**:
   - Rounded pill tags with 1-pixel borders and low-opacity background tints.
   - Distinct semantic colors: Verified (Emerald), Pending (Amber), Alert (Rose), Statutory (Navy/Indigo).

4. **Responsive Integrity**:
   - Clean stacking from 1-column on mobile to 12-column grids on desktop.
   - Touch-friendly hit targets (minimum 44px height for buttons and inputs).
